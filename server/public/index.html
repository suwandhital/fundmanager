Backend API Architecture

Production RESTful endpoints running on Azure App Service Node.js 22 LTS.

GET /api/version Returns application version, OTA status & latest APK URL Public
GET /api/manifest Expo Updates v1 protocol manifest for Over-The-Air bundles OTA Core
GET /download/apk Direct download route for the Android APK installer Download
POST /api/auth/login Authenticates user against MongoDB Atlas & issues JWT token Auth
POST /api/auth/register Creates new user account with hashed password credentials Auth
GET /api/transactions Retrieves all transactions for the authenticated user Data
POST /api/sync Bulk upsert synchronization between device and MongoDB Atlas Sync Engine
